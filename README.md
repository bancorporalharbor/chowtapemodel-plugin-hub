## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Hysteresis Model** | Physical magnetic hysteresis modeling for authentic tape saturation |
| **Wow and Flutter** | Modeled wow and flutter add vintage pitch instability to the sound |
